# tmux plugins installed by `make tmux-plugins`, one per line:
#
#   <directory>  <git url>  <commit>
#
# The directory is the repo name, which is where tpm looks for a plugin named
# owner/repo in a `set -g @plugin` line of .tmux.conf. Every @plugin line must
# have an entry here and vice versa; tests/tmuxplugins_test.go enforces it.
#
# Pinned by full commit rather than tag because the catppuccin fork has no tags.
# To upgrade, change the commit and run `make tmux-plugins` again. Updating from
# inside tmux (prefix + U) moves the plugins off these pins until the next run.
